# Contributing to useyona/einvoice-php

## Development setup

```bash
git clone https://github.com/Elyonar/einvoice-php.git
cd einvoice-php
make install        # composer install
make test
make lint
```

PHP 8.1 or newer, Composer 2. `make sync` needs git and Node 22: the models, the API snapshot and
the webhook test vectors are generated by [einvoice-js](https://github.com/Elyonar/einvoice-js), the
source of truth for every Yona SDK, at the einvoice-js commit (or tag) pinned in `scripts/sync.sh`.
Never edit `src/Generated/Types.php`, `scripts/openapi-api-key-ops.json` or
`tests/vectors/webhook-signature.json` by hand.

## Commit convention

[Conventional Commits](https://www.conventionalcommits.org/): `<type>(<scope>): <subject>`.

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`.
Scopes: `client`, `invoices`, `submissions`, `output`, `items`, `reference`, `inbound`, `sellers`,
`buyers`, `billing`, `webhooks`, `organization`, `parity`, `smoke`, `types`, `config`, `deps`, `release`.

## Pull requests

- `make lint` (phpstan level 8, php-cs-fixer PSR-12) and `make test` must pass (CI runs them on PHP
  8.1–8.4 with a coverage gate of 80 %, plus `make sync-check` and `make guides-check`).
- A new or changed method keeps parity with the snapshot (`tests/ParityTest.php`) and is named as
  einvoice-js names it (`camelCase`, the same name).
- Update the README's API reference and the CHANGELOG.
